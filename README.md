# 3D FPS Shooter

A 3D first-person shooter game built with **Godot Engine 4.4.1**.

## 🎮 About the Game

3D FPS Shooter is a personal game development project focused on the first-person shooter experience.

This repository contains the game's source code, scenes, scripts, assets, and project configuration.

## 🛠️ Built With

- [Godot Engine 4.4.1](https://godotengine.org/)
- GDScript
- Opera GX SDK integration

## 🚀 Getting Started

### Run from the source code

1. Install Godot Engine 4.4.1.
2. Clone or download this repository.
3. Open Godot.
4. Import the project by selecting `project.godot`.
5. Open the project and press **F6** or **F5** to run it.
